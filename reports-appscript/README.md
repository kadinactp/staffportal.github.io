# Reports Centre setup (preview)
Copy Code.gs, Reports.html (create HTML file named Reports), and appsscript.json into the existing Apps Script project. In Project Settings > Script properties, add ALLOWED_VIEWERS (comma-separated exact staff Google account emails) and APPROVED_SENDERS (comma-separated report sender addresses). Sender filtering is not cryptographic sender authentication; use dedicated report mailbox and confirm expected senders. Do not include guest or financial reports unless every allowed viewer is authorised. Deploy as Web app, execute as Me (staff mailbox), access only users in Kadina Workspace domain. Never select Anyone. Session.getActiveUser().getEmail() may be blank depending on Workspace policy; service denies access if blank. Test with authorised account, unauthorised same-domain account and external account before linking. Use the /exec deployment URL in index.html reportsUrl only after validation. No public report data or secrets in GitHub. The report library opens separately rather than embedding to retain Google authentication. Browser PDF preview may be limited by Apps Script iframe sandbox; download fallback available. 90-day / 200 report limit, 10 MB per PDF. Refresh retrieves new reports; no background trigger. No deployment performed from GitHub. Existing portal security rules and historical credentials require separate review.
